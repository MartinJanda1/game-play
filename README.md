# Game play

Jednoduchá webová aplikace s hrami (jeden soubor `index.html`):

- **Kolo** — styl Máme rádi Česko
- **Ruleta** — evropská 0–36
- **Karty** — balíček 52 karet
- **Kostky** — tři kostky, součet

U každé hry lze nastavit počet hráčů; historie je oddělená podle her.

## Lokálně

Otevři `index.html` v prohlížeči, nebo:

```bash
npx --yes serve . -p 3456
```
